EarnPro — اصل Full-Stack Project

اہم بات:
یہ project صرف static HTML demo نہیں ہے۔ اس میں Node.js/Express backend اور SQLite database شامل ہیں۔
تاہم Ads کی اصل آمدنی اور حقیقی payment payout کے لیے منظور شدہ ad network/payment provider اور hosting configuration الگ سے درکار ہوگی۔

کمپیوٹر پر چلانے کا طریقہ:
1) Node.js انسٹال کریں۔
2) اس فولڈر میں Terminal/CMD کھولیں۔
3) چلائیں: npm install
4) پھر: npm start
5) Chrome میں کھولیں: http://localhost:3000

فون پر:
فون پر صرف index.html کھولنے سے backend/database نہیں چلے گا۔ مکمل system چلانے کے لیے اسے Node.js والی hosting/server پر deploy کرنا ہوگا۔
